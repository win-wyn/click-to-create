# Click to Guide

**AI ทำให้ครั้งแรก และสร้างคู่มือไว้ให้ผู้ใช้ทำเองได้ในครั้งถัดไป**

An instruction-only AI skill that captures key screenshots during repeatable Browser or Computer Use tasks and turns the observed workflow into a concise Thai manual in **HTML + PDF**.

**Free for personal and business use, including paid client work. Selling the skill, adapted versions, or bundling the skill into a paid package requires prior written permission. Keep the original credit and license notices.** See [LICENSE](LICENSE).

ชื่อสกิลและคำสั่งเรียกใช้คือ `$task-to-manual` ตัวอย่างงาน เช่น ส่งออกรายงาน อัปโหลดไฟล์ หรือเปลี่ยนค่าตั้งในแอป

**สถานะ: ทดลองใช้งาน (Experimental)** — ไม่ใช่โปรแกรมบันทึกหน้าจอ และไม่ได้เพิ่มเครื่องมือ Browser/Computer ให้ AI การเลือกใช้สกิลขึ้นกับระบบและเครื่องมือของผู้รับ ไม่มีการรับรองจำนวนโทเคนที่จะประหยัดได้

## สิ่งที่จะได้

- คู่มือภาษาไทยจากขั้นตอนที่ทำจริง: `หน้า → ปุ่ม → ค่า → ผลที่ควรเห็น`
- ภาพหน้าจอเฉพาะจุดสำคัญ พร้อมหมายเลขและการปิดบังข้อมูลลับ
- HTML ไฟล์เดียวที่ฝังภาพไว้ และ PDF จากต้นฉบับเดียวกัน
- ข้อจำกัดตามจริงเมื่อทำงานไม่ครบ หรือเครื่องมือสร้าง/ตรวจ PDF ใช้ไม่ได้

สกิลจะพิจารณางานที่ทำซ้ำได้ ข้ามการค้นข้อมูลทั่วไปและคู่มือเดิมที่ยังใช้ได้ ผู้ใช้สั่งไม่ให้สร้างคู่มือหรือเลือกรูปแบบไฟล์อื่นได้

## สิ่งที่ต้องมี

1. AI ที่รองรับ Agent Skills และอ่าน `SKILL.md` ได้
2. เครื่องมือ Browser หรือ Computer Use ที่โต้ตอบกับแอปและเก็บภาพหน้าจอเป็นไฟล์ได้ พร้อมสิทธิ์เข้าใช้งานแอปนั้น
3. เครื่องมือเขียน HTML และส่งออก PDF พร้อมวิธีเปิดตรวจเอกสารหรือแปลง PDF เป็นภาพ
4. ฟอนต์ที่แสดงภาษาไทยได้ และตำแหน่งเก็บไฟล์ที่ผู้ใช้ตกลงแล้ว

Repository นี้มีเฉพาะคำสั่งสกิลและ metadata ไม่มีโปรแกรมติดตั้ง ไม่มี API key และไม่ติดตั้งส่วนเสริมให้อัตโนมัติ สกิล `pdf` และ `illustrated-web-manual` เป็นตัวช่วยเสริมเมื่อมีให้ใช้ ไม่ได้รวมอยู่ในชุดนี้

หากไม่มีเครื่องมือสร้าง PDF สกิลต้องแจ้งและส่ง HTML ที่ทำได้ก่อน ไม่อ้างว่าส่งครบทั้งสองไฟล์

## ติดตั้ง

อ่าน [LICENSE](LICENSE) ก่อนติดตั้งหรือใช้งาน ใช้และปรับแต่งได้ฟรีทั้งส่วนตัว ในบริษัท และงานรับจ้างที่ใช้สกิลสร้างคู่มือหรือผลลัพธ์ให้ลูกค้า ไม่ต้องขออนุญาตรายครั้ง

**ต้องขออนุญาตก่อนเฉพาะการนำตัวสกิล ฉบับดัดแปลง หรือเนื้อหาที่ใบอนุญาตครอบคลุมไปขาย ให้เข้าถึงแบบคิดเงิน หรือรวมในแพ็กเกจที่จำหน่าย** การใช้สร้างคู่มือให้ลูกค้าและคิดค่าจัดทำคู่มือทำได้ตามเงื่อนไข ไม่ใช่การขายตัวสกิล

สำหรับระบบที่มี Skill Installer ใช้คำสั่ง:

```text
ใช้ $skill-installer ติดตั้งสกิลจาก
https://github.com/win-wyn/click-to-guide/tree/main/skills/task-to-manual
```

ติดตั้งโฟลเดอร์ [`skills/task-to-manual`](skills/task-to-manual) ด้วย Skill Installer ที่ระบบของคุณรองรับ หรือดาวน์โหลด repository ผ่าน **Code → Download ZIP** แล้วนำเฉพาะโฟลเดอร์ `task-to-manual` ไปไว้ในตำแหน่งสกิลที่ระบบของคุณอ่าน

สำหรับ Codex ตามเอกสารปัจจุบัน ใช้ `.agents/skills/task-to-manual` ภายในโปรเจกต์ หรือ `~/.agents/skills/task-to-manual` สำหรับผู้ใช้หนึ่งคน หากติดตั้งผ่าน Skill Installer ให้ใช้ตำแหน่งที่ตัวติดตั้งของรุ่นนั้นรองรับ ดู [เอกสารทางการเรื่อง Skills](https://learn.chatgpt.com/docs/build-skills)

หลังติดตั้งให้ตรวจว่ามีสกิลในรายการ หากไม่ปรากฏให้เริ่มแอปใหม่ ระวังติดตั้งชื่อเดียวกันซ้ำหลายตำแหน่ง

## เรียกใช้

```text
ใช้ $task-to-manual ช่วยอัปโหลดไฟล์ชุดนี้ขึ้น GitHub พร้อมเก็บภาพขั้นตอนจริง
และสร้างคู่มือ HTML + PDF ไว้ให้ฉันทำตามครั้งถัดไป
เก็บคู่มือใน [ตำแหน่งที่ฉันอนุมัติ]
```

หรือสั่งงานตามปกติ ระบบที่รองรับการเลือกสกิลอัตโนมัติอาจพิจารณาเรียกใช้เมื่อเห็นว่าเป็นงานผ่านหน้าจอที่ทำซ้ำได้ การมีสกิลในเครื่องไม่ได้รับประกันว่าทุกแชตโหลดแล้ว

## ข้อมูลและสิทธิ์

- ภาพจริงเป็นหลัก ภาพ Gen ใช้ประกอบและต้องระบุสถานะ ไม่ใช้ยืนยัน UI ที่ไม่ได้เห็นจริง
- คู่มือไม่เพิ่มสิทธิ์ทำธุรกรรม ส่งข้อมูล หรือเผยแพร่ข้อมูลนอกงานที่ผู้ใช้อนุญาต
- ต้องตรวจข้อมูลลับในภาพและเอกสารก่อนส่งต่อ โดยเฉพาะรหัสผ่าน OTP token และข้อมูลบุคคลที่ไม่จำเป็น
- ตรวจชื่อปุ่มและวันที่อ้างอิงก่อนใช้คู่มือเก่า เพราะหน้าจอและขั้นตอนอาจเปลี่ยน
- HTML ที่เปิดดูและ PDF ที่ตรวจแล้ว ไม่ได้แปลว่าผู้อ่านทดลองทำตามสำเร็จแล้ว
