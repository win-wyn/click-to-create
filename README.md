# Click-to-Create

**AI ทำให้ครั้งแรก และสร้างคู่มือไว้ให้ผู้ใช้ทำเองได้ในครั้งถัดไป**

ชุดคำสั่ง AI Skills ที่พัฒนาต่อจาก Click to Guide / task-to-manual แยกผลลัพธ์เป็น **PDF, Web และ Video** เลือกอย่างเดียวหรือหลายอย่างได้ ไม่มีข้อบังคับให้ PDF ต้องพ่วงเว็บ

| สกิล | ใช้ทำอะไร | สถานะรุ่นนี้ |
| --- | --- | --- |
| [Click-to-PDF](skills/click-to-pdf) | คู่มือ PDF พร้อมภาพจริง อ่าน ส่งต่อ และพิมพ์ | ปรับคำสั่งแยกแล้ว; กระบวนการ PDF เดิมเคยทดลอง รุ่นแยกยังไม่ทดสอบครบ |
| [Click-to-Web](skills/click-to-web) | เว็บคู่มือ HTML แบบโต้ตอบ | ปรับคำสั่งแยกแล้ว; เว็บโต้ตอบรุ่นใหม่และส่วนเชื่อม AI ยังไม่ทดสอบครบ |
| [Click-to-Video](skills/click-to-video) | วิดีโอสอนขั้นตอนหรือ showcase จากหลักฐานเดิม | Experimental; มีคำสั่ง workflow แต่ยังไม่ทดสอบผลิต MP4 ครบกระบวนการ |

Repository นี้แจกคำสั่งและเอกสาร ไม่ได้รวมแอปสำเร็จรูป ตัว render วิดีโอ เครื่องมือ Browser/Computer บัญชี AI หรือบริการ hosting การทำงานจริงขึ้นกับเครื่องมือและสิทธิ์ของผู้ใช้แต่ละคน

## เลือกสิ่งที่จะสร้าง

เมื่อสั่งใช้ชุดโดยยังไม่ระบุผลลัพธ์ AI ต้องถามก่อนว่า **“ต้องการ PDF / Web / Video อะไรบ้าง? เลือกได้มากกว่าหนึ่ง”** แล้วรอคำตอบก่อนสร้าง หากระบุชัดแล้ว เช่น PDF อย่างเดียว หรือเรียก `$click-to-pdf` ถือว่าเลือก PDF แล้ว ไม่ต้องถามซ้ำหรือเพิ่มเว็บให้เอง

ตัวอย่าง:

```text
ใช้ชุด Click-to-Create ช่วยทำงานนี้และเก็บวิธีทำให้ด้วย
ก่อนเริ่มให้ถามว่าจะเอา PDF / Web / Video อะไรบ้าง
```

```text
ใช้ $click-to-pdf ทำคู่มือวิธีแก้ README บน GitHub เอา PDF อย่างเดียว
```

```text
ใช้ $click-to-web และ $click-to-pdf ทำเว็บคู่มือกับ PDF จากขั้นตอนเดียวกัน
```

ชื่อ Click-to-Create เป็นชื่อชุดใน Repo นี้ ไม่ใช่สกิลตัวที่สี่หรือคำสั่ง `$click-to-create` การเรียกด้วยชื่อชุดขึ้นกับว่า AI เห็นสกิลและอ่านคำสั่งได้หรือไม่

## ติดตั้งและอัปเกรดจากชุดเดิม

ดาวน์โหลดผ่าน **Code → Download ZIP** แล้วนำโฟลเดอร์สกิลที่ต้องการจาก `skills/` ไปไว้ในตำแหน่งสกิลที่ระบบ AI ของคุณรองรับ แต่ละโฟลเดอร์มีคำสั่ง references metadata และ LICENSE ครบ จึงเลือกติดตั้งบางรูปแบบได้

ถ้าระบบมี Skill Installer ใช้คำขอเช่น:

```text
ใช้ Skill Installer ติดตั้งสกิลจาก Repo
https://github.com/win-wyn/click-to-create
โดยเลือก skills/click-to-pdf, skills/click-to-web และ skills/click-to-video
```

อัปเกรดโดยสำรอง `task-to-manual` เดิมไว้นอกตำแหน่งที่ระบบค้นสกิล แล้วใช้สามชื่อใหม่แทน อย่าเปิดชุดเก่าคู่กันจนยังบังคับ HTML + PDF ทุกงาน ย้ายค่าคลังส่วนตัวไปสกิลใหม่ตามสิทธิ์เดิม และตรวจว่าสกิลปรากฏในระบบก่อนใช้งาน ไม่รับรองว่าแชตที่เปิดค้างอยู่จะเปลี่ยนรายการสกิลทันที

## เนื้อหาและดีไซน์ร่วมกัน

เก็บขั้นตอนจากงานจริงในรูป `หน้า → ปุ่ม → ค่า/สิ่งที่เลือก → ผลที่ควรเห็น` ใช้ภาพจริงที่ปิดบังข้อมูลลับ และใช้เนื้อหาชุดเดียวกันในผลลัพธ์ที่เลือก ดู [DESIGN.md](DESIGN.md)

- PDF มีการจัดหน้าสำหรับอ่านและพิมพ์โดยเฉพาะ ไม่ต้องรับไฟล์เว็บร่วมด้วย
- Web มีเลือกขั้นตอน ย้อนกลับ/ถัดไป ขยายภาพ และสามปุ่ม เล่นสาธิต / เปิดเว็บทำเอง / ให้ AI ทำให้ ปุ่ม AI ทำงานจริงต้องเชื่อมบัญชี AI ของผู้ใช้ หากยังไม่เชื่อมต้องแสดง “ยังไม่ได้เชื่อมต่อ AI”
- Video สร้างจากข้อมูลเดิมได้โดยไม่ต้องสร้าง PDF/Web ก่อน การเล่นสาธิตบนเว็บไม่ใช่หลักฐานว่าผลิต MP4 แล้ว

ไม่เพิ่มบริการ เสียง ดนตรี การติดตั้ง หรือค่าใช้จ่ายโดยไม่ได้รับอนุญาต หากเครื่องมือทำผลลัพธ์ที่เลือกไม่ได้ ให้แจ้งส่วนค้าง ไม่สร้างรูปแบบอื่นทดแทนเอง

## คลังกลาง

รองรับแนวทาง Google Drive เก็บไฟล์ + Google Sheets เป็นทะเบียนค้นหา ตั้งค่าบัญชี โฟลเดอร์ ตาราง และสิทธิ์ครั้งแรกกับ AI ของคุณเอง ไม่มีคลังกลางของผู้สร้างที่รับข้อมูลของผู้ดาวน์โหลดไปโดยอัตโนมัติ

ค่าตั้งของแต่ละสกิลเก็บที่ `library.local.json` ในโฟลเดอร์สกิล เก็บเพียงบัญชีและปลายทาง ไม่ใส่ token/รหัสผ่าน และไม่อัปโหลดไฟล์นี้ขึ้น GitHub เมื่อติดตั้งหลายสกิลให้ใช้ปลายทางเดียวกันที่ผู้ใช้อนุมัติ ถ้าพบค่าขัดกันให้เลือกกับผู้ใช้ก่อนเขียน ไม่สร้างคลังใหม่เงียบ ๆ

หนึ่งรายการในทะเบียนต่อหนึ่งงาน เติมเฉพาะช่อง PDF / HTML / เว็บ / Video ที่สร้างจริง แก้งานเดิมให้อัปเดตรายการเดิม ตรวจลิงก์หลังอัปโหลดแล้วส่งลิงก์ทะเบียนกลับ การเก็บ HTML บน Drive ไม่ใช่การเผยแพร่เว็บ คลังไม่ดึงงานจากทุกแชตย้อนหลังเอง

## ขอบเขตการตรวจ

ก่อนแยกชุด เคยทดลองทำคู่มือเผยแพร่และแก้ไข GitHub เป็น HTML + PDF และเก็บคู่มือ 2 ชุดในคลังส่วนตัวแล้ว การทดลองเดิมไม่ใช่ผลทดสอบสามสกิลรุ่นแยกนี้หรือการติดตั้งบนเครื่องใหม่ รุ่นนี้เผยแพร่โครงสร้างและคำสั่งเพื่อทดลองใช้ ไม่รับรองการทำงานกับ AI ทุกผลิตภัณฑ์หรือจำนวนโทเคนที่ประหยัดได้
