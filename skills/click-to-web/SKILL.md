# Click-to-Web

สร้างเว็บคู่มือภาษาไทยแบบโต้ตอบจากงานจริง เว็บอย่างเดียวไม่ต้องสร้าง PDF หรือ MP4 คู่กัน

1. อ่าน [references/workflow.md](references/workflow.md) เพื่อยืนยันรูปแบบ ขอบเขต หลักฐาน และที่เก็บก่อนเริ่ม
2. อ่าน [references/design.md](references/design.md) เฉพาะกติกากลางและ Web สร้าง HTML ไฟล์เดียวที่อ่าน/เล่นสาธิตได้โดยไม่ติดตั้งบริการเพิ่ม
3. ให้เลือกขั้นตอน ย้อนกลับ/ถัดไป ขยายภาพ และมี เล่นสาธิต / เปิดเว็บทำเอง / ให้ AI ทำให้ ตามกติกาดีไซน์ ปุ่ม AI ใช้บัญชีของผู้ใช้แต่ละคนและต้องแสดงสถานะตามส่วนเชื่อมจริง
4. เปิดไฟล์ส่งมอบทดสอบปุ่ม การอ่านไทย ภาพ ลิงก์ ปุ่ม AI ที่เชื่อมแล้ว และข้อมูลลับ หากไม่มีส่วนเชื่อมให้แสดง ยังไม่ได้เชื่อมต่อ AI ไม่อ้างว่าสามารถสั่ง AI จริงได้แล้ว
5. อ่าน [references/library.md](references/library.md) และเก็บ HTML/ลิงก์เว็บจริงตามสิทธิ์ที่ตกลง การอัปโหลด HTML ไม่ใช่การเผยแพร่เว็บ สรุปผลตรวจและส่วนค้าง
