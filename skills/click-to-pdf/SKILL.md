# Click-to-PDF

สร้างคู่มือ PDF ภาษาไทยจากงานจริงตามผลลัพธ์ที่ผู้ใช้เลือก PDF อย่างเดียวไม่ต้องสร้างหรือส่งเว็บคู่กัน

1. อ่าน [references/workflow.md](references/workflow.md) เพื่อยืนยันรูปแบบ ขอบเขต หลักฐาน และที่เก็บก่อนเริ่ม
2. อ่าน [references/design.md](references/design.md) เฉพาะกติกากลางและ PDF ใช้สกิล pdf เมื่อมีให้ใช้ รักษาข้อกำหนดการ render และตรวจทุกหน้า
3. สร้างเนื้อหาจากขั้นตอนที่ตรวจแล้ว แยกค่าตัวอย่างและค่าที่ต้องเลือกเอง จัดหน้าให้ภาพกับขั้นตอนสัมพันธ์กัน ไฟล์ HTML สำหรับพิมพ์ภายในไม่ใช่ผลลัพธ์เว็บที่ผู้ใช้ต้องรับ
4. ตรวจ PDF จริงว่าภาษาไทย ภาพ หมายเลข ลิงก์ และการตัดหน้าถูกต้อง หากทำไม่ได้ให้ระบุส่วนค้าง ไม่เพิ่ม HTML เป็นผลลัพธ์ทดแทนเอง
5. อ่าน [references/library.md](references/library.md) และเก็บเฉพาะไฟล์ที่ผู้ใช้เลือกในคลังเดิม รายงานผลตรวจและลิงก์ที่บันทึกแล้ว
