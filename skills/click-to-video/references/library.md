# คลังคู่มือกลาง — Google Drive + Google Sheets

อ่านเมื่อค้นคู่มือเดิม ตั้งคลังครั้งแรก หรือส่งมอบคู่มือที่สร้าง/ปรับเสร็จแล้ว ใช้เครื่องมือ Drive/Sheets ที่มีสิทธิ์อยู่ และอ่านสกิลเฉพาะเครื่องมือเมื่อมี ไม่ติดตั้งหรือเชื่อมบัญชีเพิ่มเอง

## ตั้งค่าครั้งแรกและใช้ซ้ำข้ามแชต

- อ่าน `library.local.json` ที่รากโฟลเดอร์สกิลเมื่อต้องใช้คลัง ไฟล์นี้เป็นค่าของผู้ใช้แต่ละคน ไม่ใช่ไฟล์แจก ห้ามใส่รหัสผ่าน token หรือข้อมูลเข้าใช้งาน
- หากไม่มีค่าตั้ง ให้ถามบัญชี โฟลเดอร์ Drive ตาราง Sheets และการแชร์ก่อนสร้าง/อัปโหลด เสนอชื่อ Custom Skill.md Library / ทะเบียนคู่มือ และสิทธิ์ส่วนตัวได้ แต่ไม่ถือเป็นค่าอนุมัติอัตโนมัติ
- เก็บ account ที่ผู้ใช้เลือก, folder URL/ID, spreadsheet URL/ID, ชื่อแท็บจริง และขอบเขตการบันทึกที่ตกลงในไฟล์ค่าตั้ง หลังตรวจปลายทางจริงแล้ว ไม่เดา URL/ID หรือใช้ connection ID ของคนเดิมกับผู้ใช้ใหม่
- การอนุมัติคลังให้บันทึกคู่มือที่สร้างด้วยสกิลตามขอบเขตที่ตกลงได้ต่อ ไม่ต้องถามซ้ำทุกไฟล์ภายในขอบเขตเดิม แต่ไม่ขยายสิทธิ์แชร์หรือย้ายไฟล์เดิมเอง ผู้ใช้ปฏิเสธการบันทึกเฉพาะงานได้
- ข้ามแชตใช้ค่าตั้งเดิมได้เมื่อแชตนั้นโหลดสกิล อ่านไฟล์ค่าตั้งได้ และมีเครื่องมือเข้าถึงบัญชีนั้น ไม่ใช่ระบบดึงงานจากทุกแชตอัตโนมัติ
- เมื่อแจก/อัปโหลดสกิล ใช้รายการไฟล์เผยแพร่ที่ชัดเจน และตัด `library.local.json` รวมทั้งไฟล์คู่มือและข้อมูลส่วนตัวออก แม้มี .gitignore ก็ต้องตรวจชุดส่งจริง

## ทะเบียน: หนึ่งรายการต่อหนึ่งงาน

คอลัมน์หลัก: รหัสคู่มือ | ชื่อคู่มือ | สกิลที่สร้าง | เกี่ยวกับ | ใช้ทำอะไร | PDF | HTML | เว็บคู่มือ | วิดีโอ | วันที่ตรวจขั้นตอน | วันที่บันทึก | สถานะ | หมายเหตุ

- ใช้รหัสคงที่เมื่อแก้คู่มือเดิม ชื่อสกิลเช่น Click-to-PDF / Click-to-Web / Click-to-Video ตามรูปแบบที่สร้างจริง เป็นผู้สร้าง ส่วนชื่อคู่มือเป็นชื่องานที่ผู้ใช้ค้นหา ไม่สร้างตารางซ้ำแยกทุกแชต
- ช่อง PDF/HTML/วิดีโอเก็บลิงก์ไฟล์ที่อัปโหลดจริง ช่องเว็บคู่มือใช้เฉพาะ URL เว็บที่เผยแพร่และตรวจได้ ไม่ใส่ลิงก์เว็บไซต์เป้าหมายหรือลิงก์ไฟล์ HTML บน Drive แทนเว็บที่รันได้
- วันที่ตรวจขั้นตอนอิงหลักฐานจริง แยกจากวันที่อัปโหลด ถ้าไม่ทราบให้ระบุว่าไม่ทราบ ไม่ใช้วันอัปโหลดแทน
- สถานะและหมายเหตุแยกความพร้อมของเนื้อหา การเก็บไฟล์ การเผยแพร่เว็บ และการเชื่อม AI ตามจริง เว้นช่องไฟล์/เว็บที่ยังไม่มีไว้ ไม่สร้างลิงก์คาดเดา

## ก่อนสร้างและหลังตรวจงาน

1. ค้นในทะเบียนที่ตั้งค่าไว้เฉพาะชื่องาน/ระบบที่เกี่ยวข้อง หากมีคู่มือเดิมให้ตรวจความตรงกับงานก่อนส่งลิงก์เดิมหรือปรับรายการเดิม ไม่สแกน Drive/ทุกแชต/ทั้งเครื่อง
2. หลังตรวจคู่มือ ให้ส่งเฉพาะไฟล์ส่งมอบที่ปิดบังข้อมูลแล้ว เฉพาะ PDF / HTML / Video ตามที่เลือก ไปโฟลเดอร์ที่อนุมัติ ไม่ส่งภาพดิบ วิดีโอตัวอย่าง ไฟล์ชั่วคราว หรือข้อมูลภายในอื่นโดยอัตโนมัติ
3. อ่านรายการเดิมและปลายทางก่อนเขียน ใช้ ID รายการ/ไฟล์เดิมเมื่อแก้ไข และรักษาฉบับก่อนหน้าตามความสามารถที่มี หากต้องอัปโหลดไฟล์ฉบับใหม่ ให้ปรับแถวเดิมชี้ฉบับใหม่ ไม่ลบฉบับเก่าเอง
4. บันทึกลิงก์ที่ได้จากการอัปโหลดสำเร็จในแถวเดิม หรือเพิ่มแถวใหม่เมื่อเป็นคู่มือใหม่ ตรวจค่าที่เขียนกลับและไฟล์ในโฟลเดอร์ ตรวจสิทธิ์ให้ตรงที่ตกลง ไม่เปิด anyone with link หรือ publish to web เอง
5. ถ้าอัปโหลดหรือเขียนตารางได้เพียงบางส่วน ให้เก็บ ID/ลิงก์ที่ทำสำเร็จและระบุส่วนค้าง ตรวจสถานะก่อนลองซ้ำ ห้ามสร้างโฟลเดอร์ ไฟล์ หรือแถวซ้ำเมื่อผลคำสั่งไม่ชัด
6. ส่งลิงก์ทะเบียน/รายการ พร้อมไฟล์ที่เก็บแล้วและผลตรวจ เมื่อเครื่องมือเข้าถึงคลังไม่ได้ ให้ส่งไฟล์ในเครื่องพร้อมข้อมูลรายการที่ยังรอบันทึก ไม่อ้างว่าเก็บบนคลังแล้ว

การเก็บไฟล์ HTML ไม่ใช่การเผยแพร่เว็บหรือเชื่อม AI โดยอัตโนมัติ การรวบรวมคู่มือเก่าต้องตกลงขอบเขตแหล่งข้อมูลก่อน ไม่ไล่อ่านแชตอื่นเอง

หากเลือกหลายรูปแบบของงานเดียวกัน ให้อัปเดตแถวเดียว เติมเฉพาะช่องของรูปแบบที่สร้างจริง และคงลิงก์รูปแบบเดิมที่ยังใช้ได้ ไม่เปลี่ยนชื่อผู้สร้างในรายการประวัติเก่าเพียงเพราะเปลี่ยนชื่อชุดสกิล
